# Sample Outputs

This directory contains pre-generated sample outputs that let a reviewer evaluate the
portfolio without running the full pipeline. Each file is described below, along with
instructions for regenerating the real version.

---

## Files

### `budget_vs_actual_results.md`

**What it is**: Formatted Markdown table showing the output of `sql/budget_vs_actual.sql` —
donor budget vs. actual disbursement by program, including variance and utilization rank.

**How to regenerate**:
```bash
duckdb pspl.duckdb < sql/budget_vs_actual.sql
```
Paste the output into this file as a Markdown table.

---

### `payment_success_rates_results.md`

**What it is**: Formatted Markdown table showing the output of `sql/payment_success_rates.sql` —
payment success rates by district and program, with 3-month rolling averages.

**How to regenerate**:
```bash
duckdb pspl.duckdb < sql/payment_success_rates.sql
```
Paste the output into this file as a Markdown table.

### `payment_amount_distribution.png`

**What it is**: Matplotlib histogram of payment amounts (PKR) from the `silver/payments`
Delta table, generated by Section 8 of the PySpark notebook.

**How to regenerate**:
```bash
python -m jupyter nbconvert --to notebook --execute notebooks/delta_lake_operations.ipynb \
    --output-dir notebooks --output delta_lake_operations_executed.ipynb
```
The chart is saved automatically by the notebook cell.

### `dbt_lineage_screenshot.png`

**What it is**: A placeholder diagram showing the dbt model lineage graph:

```
Sources (9 Silver Delta tables)
    → 9 Staging models (stg_*)
        → 3 Intermediate models (int_*)
            → 4 Mart models (mart_*)
```

The placeholder was generated with matplotlib because the interactive dbt docs site
requires a running DuckDB database (`pspl.duckdb`), which is produced by the
full pipeline.

**How to regenerate the real interactive version**:
```bash
# 1. Run the full pipeline first
make all

# 2. Generate and serve dbt docs
cd dbt && dbt docs generate && dbt docs serve

# 3. Open http://localhost:8080 in your browser
# 4. Click the blue graph icon (bottom-right) to open the lineage graph
# 5. Take a screenshot and save it here as dbt_lineage_screenshot.png
```

The interactive lineage graph lets you click any node to see its SQL, tests, and
upstream/downstream dependencies — a much richer view than the static placeholder.

```bash
# Full pipeline (ingest → Silver → dbt → SQL KPIs)
make all

# Then capture the dbt lineage screenshot manually (see above)
```

All other files in this directory are regenerated automatically by `make all`.
