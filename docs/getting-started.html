Prerequisites

Python 3.10+ (3.10 or 3.11 recommended for PySpark test stability), Java 11+ with JAVA_HOME, Git, and internet access on first Spark run (Maven resolves Delta JARs).

From repo root, paths below assume you have already cd into the repository folder.

Install dependencies

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

Run the full pipeline

Order: ingest Bronze → notebook Silver → dbt build/test → KPI SQL against DuckDB.

make all

Requires make, duckdb CLI, and a Unix-style shell for the KPI loop in the Makefile.

# From repository root
.\scripts\run-full-pipeline.ps1

Script runs the same stages as make all but uses PowerShell-friendly commands. Install Jupyter components from requirements.txt first.

Run one stage at a time

1. Bronze ingest (PySpark + Delta)

python ingest/ingest.py

Single dataset (example): python ingest/ingest.py --dataset beneficiaries

2. Silver notebook (non-interactive)

On Windows, jupyter is often not on PATH unless the venv is activated. Prefer the script below, or call Jupyter through the venv Python.

python -m jupyter nbconvert --to notebook --execute notebooks/delta_lake_operations.ipynb --output-dir notebooks --output delta_lake_operations_executed.ipynb
.\scripts\run-spark-notebook.ps1

Manual (same as script, no jupyter on PATH):

.\.venv\Scripts\python.exe -m jupyter nbconvert --to notebook --execute notebooks/delta_lake_operations.ipynb --output-dir notebooks --output delta_lake_operations_executed.ipynb

3. dbt (DuckDB)

Manual dbt from PowerShell needs DELTA_LAKE_PATH pointing at your delta_lake folder with forward slashes (the full pipeline script sets this). Example: $env:DELTA_LAKE_PATH = ($PWD.Path + "\delta_lake").Replace("\", "/")

cd dbt
dbt run
dbt test
cd ..

4. KPI SQL files

make sql-kpis
.\scripts\run-sql-kpis.ps1

Streamlit KPI dashboard

Requires a successful dbt run so pspl.duckdb exists at the repository root. Opens Plotly charts over marts (payments, donors, protection, refugee assistance).

.\scripts\run-dashboard.ps1

Any shell with venv active: streamlit run dashboard/streamlit_app.py from repo root.

Tests and dbt documentation

pytest tests/ -v

Optional: example Java setup then pytest on Windows: .\run_tests.ps1

cd dbt
dbt docs generate
dbt docs serve
cd ..

Clean generated artifacts

make clean
.\scripts\clean-artifacts.ps1
